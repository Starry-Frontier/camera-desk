# Camera Desk v1.2.0

新增定时拍摄、机位硬件变焦和存储预估，提供 Windows 10/11 x64 单文件 EXE 与便携版。

- 预约或立即开始录像，用户设定持续时长后自动停止并保存；普通录像按钮也可使用按时长停止。
- 按用户间隔自动拍照，可与录像同时进行；支持全部或指定机位、单路／全部取消未来任务。
- 每个机位探测标准 Windows 硬件变焦范围与步长，按设备值应用并读回确认；不支持时明确禁用。
- 显示存储参考范围、预计照片数量与磁盘余量；分辨率等选项提供清晰的下拉按钮，数值提供加减按钮。

入口为左侧“定时拍摄 / 存储预估”或机位上的“定时”。任务使用创建时的目录和格式，自动命名。预约需软件保持运行、电脑不休眠；错过超过 60 秒会取消。退出取消未来任务，重启不恢复；已接受的文件保存会完成。忙碌时可能跳过拍照轮次。

存储是宽泛参考，实际编码大小取决于画面内容，不能保证磁盘容量。硬件变焦需要摄像头与驱动通过标准接口支持；模拟测试不替代实体镜头与 8 台 USB 摄像头验证。此前重复补帧问题仍未修复。

发行附件包含单文件 EXE、完整便携包、MIT 应用源码、对应第三方源码及 SHA-256 校验文件。
