# Camera Desk v1.1.1

录像时点击拍照即可直接保存，不再弹出保存窗口。

- 单机位“拍照”和顶部“全部拍照”使用左侧预设目录与图片格式，自动生成含时间、序号、机位编号的文件名。
- 多路照片默认在同一文件夹。连续快速拍照或出现同名文件时自动换名，不覆盖原照片、不弹确认窗口。
- 原录像继续写入原文件；拍照按钮右侧箭头提供“另存为”入口，可手动命名和选择位置／格式。
- 保留 PNG、JPEG、BMP、TIFF、WebP 图片与 AVI、MP4、MKV 视频选择，以及全部／分机位录制。

25 项模拟机位回归测试通过。多台实体摄像头和其他 Windows 电脑仍需实测。

Windows 10/11 x64：下载 `CameraDesk-Windows-x64.zip`，解压完整文件夹后运行 `CameraDesk.exe`，无需 Python；保留 `_internal`。MIT 应用源码及第三方对应源码作为独立附件提供，GitHub 发行结构与之前版本一致。
