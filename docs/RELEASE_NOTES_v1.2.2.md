# Camera Desk v1.2.2

修复拍照间隔无法直接调整的问题，并支持在任务进行中修改间隔。

- 新建任务的拍照间隔始终可编辑；修改后自动选择“间隔自动拍照”。可输入 0.1～86400 秒，独立加减按钮每次调整 0.1 秒。
- 已创建任务可通过左侧“调整拍照间隔…”选择全部或单个机位，或点击对应机位“间隔”。支持进行中和已预约的拍照任务。
- 进行中的任务从应用时刻按新间隔计时，新间隔后拍下一张，原定结束时刻不变；预约任务保留原开始时刻。取消调整不改变任务。
- 原有录像继续写入同一文件；照片保存位置、格式和机位命名保持原设置。界面显示当前实际拍照间隔。
- 增加实际输入、按钮点击、运行中拍照频率变化、单路隔离、全部修改与录像连续性的自动化验证；发行流程同时检查便携版与单文件版。

提供 Windows 10/11 x64 单文件 EXE、便携版、MIT 应用源码、第三方对应源码和 SHA-256 校验值。旧发行版、标签和更新记录保留。
