# Camera Desk v1.2.1

改进定时拍照的日期和时刻选择，保留 v1.2.0 的定时录像、间隔拍照、硬件变焦和存储预估。

- 预约日期与时刻分开显示：日历选择日期，独立的时、分、秒可直接输入或点击加减。
- 日期和时刻不再因为默认“立即开始”而置灰；编辑任一项会自动选择预约模式，并给出说明。
- 切换拍摄方式保留已选时刻；明确选择“立即开始”时使用当前时间，不会误用预约日期。
- 新增真实键盘输入、日历和加减点击、按选择时间执行拍照，以及打包 EXE 时间选择检查。

入口：左侧“定时拍摄 / 存储预估”或机位“定时”→ 选择“间隔自动拍照”→ 选择日期和时、分、秒 → 设置持续时间、拍照间隔 → 创建任务。

提供 Windows 10/11 x64 单文件 EXE、便携版、MIT 应用源码、第三方对应源码和 SHA-256 校验值。保留旧发行版与完整 CHANGELOG；硬件变焦与实际拍摄性能仍取决于设备，存储为参考估算。
