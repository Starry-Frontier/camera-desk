# Camera Desk v1.1.0

本次统一整合路径命名、多路录制、录像中拍照和格式选择，并保留各机位独立分辨率、图像调整及镜像功能。

- 拍照和开始录像前选择保存目录、文件名；多路共用一个默认文件夹，可统一命名或逐机位改名。
- “全部开始录像”和“全部停止录像”分开，各机位仍可独立开始、停止。已有录像时只补开其余机位，原文件继续录制。
- 录像中可以单路／全部拍照；照片独立保存，慢速或失败的照片任务不主动中断录像。
- 图片支持 PNG、JPEG、BMP、TIFF、WebP；视频支持 AVI、MP4、MKV，均为无声录像。
- 格式可在侧边栏及保存窗口选择，保留自定义名称并更新后缀；选择被记住，当前录像格式保持不变。
- 同名文件确认后才替换，已存在录像保留至新录像成功完成并可读取；取消保存不会启动新拍摄。

24 项模拟机位自动化测试通过。多实体机位和其他 Windows 电脑仍需实测；“全部开始”不提供硬件级帧同步。

使用者下载 `CameraDesk-Windows-x64.zip`，解压完整 `CameraDesk` 文件夹后运行 `CameraDesk.exe`，支持 Windows 10/11 x64，无需 Python。保留 `_internal` 文件夹。

开发者下载 `CameraDesk-Source.zip`；应用采用 MIT 许可证，包含 GitHub 自动测试与发行流程。第三方组件及其对应源码见 `CameraDesk-ThirdParty-Sources.zip`、`THIRD_PARTY.md` 与 `LICENSES`，文件校验值见 `SHA256SUMS.txt`。本版依赖版本与 v1.0.1 相同。
