# Camera Desk v1.0.1

修复逐机位分辨率切换，新增设备采集尺寸与输出尺寸区分。

- 右侧下拉框明确选择摄像头，每台分别保留分辨率与帧率选择。
- 读取设备报告的格式，允许输入自定义输出宽高。
- 切换对应机位的采集连接，并用真实图像核对尺寸；其他机位继续运行。
- 设备无法原生切换时，默认将画面缩放至所选输出尺寸，并清楚标注。照片和录像使用相同输出尺寸。
- 提供“仅相机原生分辨率（禁止缩放）”选项；原生切换失败时恢复原画面。

在当前 `Web Camera` 上实测：设备采集尺寸固定为 2560 × 1440，输出可在 640 × 480、1920 × 1080、1280 × 720 间独立切换，并标记软件缩放。另一路模拟预览持续运行。多实体摄像头仍需实测。

Windows 10 / 11 x64 便携版无需安装 Python。下载 `CameraDesk-Windows-x64.zip`，解压完整文件夹后运行 `CameraDesk.exe`。应用源码为 MIT 许可证；第三方依赖及许可证沿用 v1.0.0 的相同版本。
