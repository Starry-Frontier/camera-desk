# v1.1.2 整合修改清单

用户要求：所有所列修改完成后统一打包。功能在 v1.1.1 完成，v1.1.2 新增内置运行组件的单文件 EXE，并保留便携文件夹版；两种打包程序均通过 8 路模拟录像和录像中拍照检查。完整验证范围见 `VALIDATION.md`。

## 已完成：照片和录像选择路径、命名

- 普通拍照直接保存，拍照按钮右侧“另存为”可手动选择目录、名称和图片格式；开始录像时可选择目录、名称和视频格式。
- 全部拍照／全部开始录像：一次选择目录和统一名称，各机位文件名可单独编辑。
- 取消不拍照／不开始录像；停止录像不弹保存窗口。
- 同名文件显式确认替换，批量同名、正在使用的录像名、无效 Windows 文件名提前拒绝。
- 原录像保留至新录像成功完成并可解码后，再执行已确认的替换；记住最后使用的目录。
- 已验证中文路径、命名、批量保存、取消、拒绝覆盖、保存失败保护原文件及之前的分辨率修复。

## 已完成：多路文件默认保存在同一文件夹

- 多路同时拍照或录像只使用一个统一保存文件夹，不按摄像头分别建立目录；文件以机位编号或自定义名称区分。
- 默认沿用侧边栏设置的目录，后续批次及重新启动后记住最近选择的共同目录。
- 保存窗口明确标出“统一保存文件夹”，并校验批次中的所有目标文件位于所选同一目录。
- 已验证默认目录直接拍照／录像、跨重启目录记忆以及不同机位目录不一致时的拒绝检查。

## 已完成：同时录像与分机位独立开始录像

- 顶部分别提供“全部开始录像”和“全部停止录像”；每个机位仍有独立的录制／停止按钮。
- 已有录像时，全局开始只补开其余可用机位，原录像保持连续，文件名与路径不变。
- 单独停止、重新开始一个机位不影响其他机位；两种操作方式可以交替混用。
- 全部停止也会取消正在开始的录像；正在保存时防止重复操作，一路开始失败不阻塞其他路。
- 已验证错开开始、单独停止、已有录像时补开其余机位、取消批量操作、统一停止启动中的录像、一路失败隔离和实际录像文件可读性。

## 已完成：录像过程中同时拍照

- 单路和全部拍照在录像中保持可用，不主动停止或重启现有录像。
- 照片保存任务有数量上限，独立编码和写盘；慢速或失败照片不阻塞录像采集，退出时等待已接受的照片完成。

## 已完成：可选择图片与视频格式

- 图片：PNG、JPEG、BMP、TIFF、WebP；视频：AVI、MP4、MKV。
- 侧边栏设置默认格式，单机位／批量保存时也可更改；名称保留、后缀随所选格式更新，重启后记住默认选择。
- 已录制文件不因修改下次视频格式而改变。
- 图片格式选择保留在左侧预设与另存为窗口，视频格式选择保留在左侧与录像保存窗口。

## 已完成：点击直接拍照，不弹保存窗口

- 普通单路与全部拍照直接写入预设共同目录，使用当前所选图片格式，自动命名。
- 时间、连续序号及机位编号保证快速点击不重名；已有目标文件自动换名，不弹覆盖确认也不覆盖旧照片。
- 手动命名仍可通过按钮右侧的“另存为”菜单使用。
- 累计 25 项回归测试通过，覆盖不调用保存窗口、快速连拍、时钟不变时的重名保护、原录像不中断，以及之前的所有功能。录像测试使用模拟机位，多实体机位仍需实机验证。

新版本保留用户现有拍摄文件；应用仍采用 MIT 许可证并提供完整 GitHub 发行结构。
