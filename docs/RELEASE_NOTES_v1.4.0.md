# Camera Desk v1.4.0

- 增加默认关闭的本机控制，可通过 HTTP、命令行和 MCP 查询机位、读取预览、拍照、录像和调整采集格式。每个实例同一时间只接受一个控制客户端，客户端可以按请求 ID 查询每次拍照的保存结果。
- 模型分析增加 Kimi 预设，支持完整请求地址，截断的回复会标记为不完整。
- 录像保存前逐帧解码校验。发现损坏时保留原文件并提示保存失败。长录像的校验会增加保存用时。
- 根据设备标识打开摄像头并读取格式和变焦能力。修复摄像头换序时机位或能力信息错配的问题。
- 多个实例共享数据目录时，分别合并采集格式和图像参数。格式切换确认时保留期间新输入的值。
- 保留小数采集帧率，修复单机位的定时路径异常、批量文件名校验、格式恢复中的错误提示，以及已关闭对话框的释放。

提供 Windows 10/11 x64 单文件 EXE、便携压缩包、MIT 应用源码、第三方对应源码和 SHA-256 校验值。CLI 和 MCP 桥接脚本随源码分发，使用 Python 标准库。

验证覆盖 129 项自动测试、模拟摄像头换序和真实文件解码。本机控制与外部模型的协议检查使用演示机位与模拟服务。
