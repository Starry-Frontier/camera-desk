# Camera Desk v1.3.0

将 2026 年 11 月 3 日、11 月 5 日其他项目对话中已完成的修复统一封装为 Windows 10/11 x64 可执行程序。

- 修复录像时间槽和尾帧处理、原生格式协商及异常配置恢复。
- 分辨率切换期间保留间隔拍照任务、结束时间与创建时的保存目录。
- 改善 8 路自动布局、设备断开后的按钮状态、保存后缀、中文确认按钮、图标和“全部停止”说明。
- 修复定时录像保存失败却误报成功、同名照片并行覆盖、退出时延迟启动机位等问题。
- 新增手动模型单帧分析：支持 OpenAI 兼容、Claude、Gemini、Grok、DeepSeek、Qwen、GLM 接口预设，可配置地址与图像模型 ID。
- 模型接口默认关闭，核心开关关闭时拦截新调用并取消本地等待；密钥仅在运行期间保留。分辨率切换后等待新帧，结果持续显示来源机位。
- 保留单路／全部录像、录像中拍照、用户选择保存位置／格式、预约拍摄、运行中拍照间隔修改、设备支持的硬件变焦和存储预估。

提供单文件 EXE、便携 ZIP、MIT 应用源码、第三方对应源码和 SHA-256 校验值；旧发行版、标签和更新记录保留。

验证范围：96 项自动测试；两种打包程序的 8 路模拟录像、录像中拍照与定时场景；本机模拟模型服务的七种预设、核心开关和包内 HTTPS 检查。云端服务需要用户自行提供有效密钥和可用图像模型；本版未进行真实账户调用或多台实体摄像头验证。
